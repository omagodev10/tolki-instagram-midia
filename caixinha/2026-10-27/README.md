# Caixinha de perguntas · 27 criativos (27/10/2026)

Reels 9:16 (1080x1920) no formato caixinha de perguntas do Instagram: pergunta de dono de clínica, resposta narrada, a IA conversando com o paciente (ou lista de etapas do CRM), card de prova real e CTA.

- `organico/`: CTA **"Comenta PALAVRA"** (palavra-chave diferente por criativo, para rastrear qual converte). Para o Claude social media agendar no Instagram.
- `anuncio/`: mesmo vídeo com CTA **"Clique no botão abaixo"**. Para o Claude tráfego subir na Meta (CA - TOLKI 4).
- Cada criativo tem `NOME.mp4` + `NOME_tela1.png` (pergunta), `_tela2.png` (conversa/lista) e `_tela3.png` (CTA), que servem de capa.
- `criativos.json`: a mesma lista em JSON, com os links diretos.

**Regras**

- Nada vai ao ar sem OK do Carlos.
- Provas usadas são só as liberadas. Conversas na tela levam "exemplo ilustrativo".
- Música: faixas sem letra da biblioteca, já mixadas no vídeo (−14 LUFS). Se a Meta silenciar algum anúncio por áudio, avisar para trocar a trilha.
- Orgânico: quem comentar a palavra precisa receber a resposta no direct (automação de palavra-chave), com o que a CTA promete (coluna "promessa").
